# AI use disclosure

**This game was made by one person directing AI tools.**
- The code and the documentation were written mostly by AI coding agents.
- Every creature model was generated by an AI 3D service.
- Every piece of concept art was generated by an AI image model.

The human part is direction:
- what to build, and in what order
- the design calls
- playtesting and judging the feel
- choosing which outputs were kept and which were thrown away

Nothing here is presented as human-made where it was not. This file is
also how the project meets the labelling terms of the services that
generated the assets (see [Obligations](#obligations-this-file-meets)).

Recorded as of 2026-10-01. The history is itself evidence: the commits carry
`Co-Authored-By` trailers, and `docs/MODEL_GENERATION.md` and
`artifacts/**/generation.json` record each model's generation.

## What is in the repository but not in the game

| Material | Made with |
|---|---|
| Concept art, creature reference sheets, turnarounds and view plates (`artifacts/dragon-options/`, `artifacts/**/concept*`) | **OpenAI GPT Image 2**: through ChatGPT Plus (via `chatgpt-imagegen`) and through Codex's built-in image tool (orchestrated by gpt-5.6-luna) |
| Art-direction targets in `docs/concept/` (HUD, vegetation, pose references) | **Google Nano Banana 2** (Gemini, via the Antigravity CLI). These carry Google's SynthID and C2PA marks; the valley key art is GPT Image 2 |
| Comparison renders of meshes that were evaluated and **not** used (`artifacts/dragon-options/embercrest-model-field.png` and siblings) | **TRELLIS.2** (Microsoft, local and on its Hugging Face Space), **Pixal3D**, **Hunyuan3D-2mv** (open weights, run locally), and one **Tripo** v2.5 mesh |
| Docs, commit messages, the capture and probe scripts | Claude and Codex, as for the code |

No prompt asks for the style of a named artist, studio or franchise. The
creature prompts explicitly forbid imitating existing franchise designs. The
prompts are in `artifacts/dragon-options/` beside the images they made.

## Obligations this file meets

- **Tencent Hunyuan 3D service agreement**: clause 3.3 of the user service
  agreement (no. TEG-101170-002-05, effective 2025-05-26). Content
  published from the service must be marked prominently as AI-generated,
  and the service's own AI marks must not be removed or hidden (3.6). This
  file, the README and the release notes are that mark. Every package of the
  game carries this file. The generated outputs belong to the user (clause
  5.3).
- **OpenAI, Google and Anthropic terms**: each forbids presenting its output
  as human-made. None of them restricts using the output in a free game.
- **Store labels**, if copies go up anywhere:
  - itch.io: *AI Generated*, sub-tags *Graphics* and *Code*.
  - Steam's content survey: "Pre-Generated" content, for the models and
    the art.
